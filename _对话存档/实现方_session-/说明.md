## 怎么看

`对话.jsonl` 是每行一个事件的文本文件，记事本 / VS Code 都能打开。

每行一个 JSON，常见 `type`：

| type | 含义 |
|---|---|
| `user/message` | 用户说的话 |
| `assistant/message` | AI 说的话 |
| `tool/call` | AI 调用了什么工具 |
| `tool/result` | 工具返回了什么 |
| `turn/start` / `turn/end` | 一轮对话的起止 |
