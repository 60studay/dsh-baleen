## ⚠️ 三条铁律（所有阶段都适用）

### 1. 不是为某一个工程写的

插件是**通用串口工具**。代码里**不允许**出现具体设备的命令字。

| 放插件本体 | 放场景配置 |
|---|---|
| 通用机制 | 具体命令、故障字、处置命令 |

**验收：代码里搜不到 `"P"`、`"FAULT"`、`"CH1"`、`"stall"`。**

### 2. 控制权必须真正生效

`human` / `paused` 状态下，AI 绝对不允许发命令。

### 3. 不阻塞主收发

附加逻辑出错只记日志，收发照常。
