## 八、已知坑

| 坑 | 规避 |
|---|---|
| `git push` 用 `credential.helper=manager` | 弹 GUI 登录框挂死 10 分钟，`GIT_TERMINAL_PROMPT=0` 关不掉。用临时凭据文件 |
| Python 文本模式写文件 | CRLF→LF，diff 虚增百倍。一律 `open(p,"rb")`/`open(p,"wb")` |
| 后台起服务加 `\| Select-Object -First N` | 管道读够就关上游，服务被杀 |
| 改 JS 后必须重启网页 | 页面在服务启动时缓存 |
| PowerShell 读中文 JSON | `Get-Content`/`ConvertFrom-Json` 按 GBK 解，会失败。用 Python |
| 拆分时漏 import | 自检测不出，要真发 HTTP 请求 |
