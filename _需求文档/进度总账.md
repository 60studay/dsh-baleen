## 七、铁律（每次改动都要过一遍）

1. **不是为某一个工程写的** —— 代码里不许出现具体设备命令字
   （验收：搜不到 `"P"` `"FAULT"` `"CH1"` `"stall"`）
2. **控制权必须真正生效** —— `human`/`paused` 下 AI 绝对不许发命令
3. **不阻塞主收发** —— 附加逻辑出错只记日志
4. **保持跨平台** —— 不许出现 `C:\\`、`if platform`、`sys.platform ==`

## 八、已知坑（踩过的，别再踩）

| 坑 | 后果 | 规避 |
|---|---|---|
| `git push` 用 `credential.helper=manager` | **弹 GUI 登录框，后台挂死 10 分钟** | 用临时凭据文件 + 推完即删 |
| Python 文本模式写文件 | CRLF→LF，diff 虚增百倍 | 一律 `open(p,"rb")` / `open(p,"wb")` |
| 拆分文件时漏 import | `/ports` 500，**自检完全测不出** | 改完立刻访问接口 |
| 轻模式 `open` 串口做"验证" | 假报占用 + **CH340 拉 DTR/RTS 复位板子** | 轻模式只扫描不 open |
| `_xxx.py` 临时脚本 | 误提交 3 次 | `.gitignore` 已挡 `_[a-zA-Z0-9]*.py` |
| **后台起服务时加 `\| Select-Object -First N`** | **管道读够 N 行就关闭上游，服务被静默杀掉**（23:08 实际发生，网页突然打不开） | 后台任务**不要接管道**，直接跑 |
| PowerShell 处理中文文件名 | `Test-Path`/`git ls-files` 循环失效 | 用 Python subprocess + UTF-8 |
| 控制台 GBK 编码 | `UnicodeEncodeError` | `sys.stdout.reconfigure(encoding="utf-8")` |
