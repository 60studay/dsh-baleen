# 文字游戏 场景协议(暗号表)

## 硬件
- 风扇: 指令 F <0-100>
- 水泵: 指令 S <0-100>
- 数字用十进制, F/S 后空格可加可不加

## 暗号表(剧情事件 -> 串口指令)
- 下雨        -> F 50 S 100
- 暴雨/雨太大 -> F 80 S 100
- 毛毛雨/雨小 -> F 20 S 30
- 放晴/停雨   -> F 0 S 0
- 起风/风大   -> F 100 S 0
- 微风        -> F 30 S 0
- 结束/退出   -> F 0 S 0

## 边界规则
- 表中没有的事件: 按最接近语义选一条发, 剧情里自然带过, 不中断对话
- 数值只发 0-100, 越界按边界处理
